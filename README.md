# Book Club — приложение для учёта прочитанных книг

Мобильное приложение на Android для ведения личного дневника чтения с отзывами, рейтингами и статистикой.

## Возможности

- Добавление книг с обложкой, автором, жанром и статусом
- Поиск по названию и автору
- Фильтрация по статусу (Планирую / Читаю / Прочитано)
- Статистика с круговой и столбчатой диаграммами
- Отзывы и рейтинг для прочитанных книг
- Заметки к каждой книге
- Тёмная тема
- Сортировка по названию, автору или статусу
- Заготовка сканера штрих-кода с запросом разрешения камеры

## Технологии

- Язык: Kotlin
- Архитектура: MVVM (ViewModel + LiveData)
- База данных: Room (SQLite)
- Навигация:Navigation Component + BottomNavigationView
- UI: Material Components, ViewBinding
- Графики: MPAndroidChart
- Загрузка обложек: Coil
- Асинхронность: Kotlin Coroutines

## Структура проекта
app/src/main/java/com/example/bookclub/
├── database/ # Room: Entity, DAO, AppDatabase
├── viewmodels/ # BookViewModel
├── ui/ # Фрагменты экранов
├── adapters/ # BookAdapter для RecyclerView
└── utils/ # Вспомогательные классы

## Модель данных

- categories — жанры книг
- books — книги (связь с категориями через FOREIGN KEY)
- tags — теги
- book_tags — промежуточная таблица (многие-ко-многим между книгами и тегами)

## Установка

1. Клонируйте репозиторий: git clone https://github.com/ваш__ник/BookClub.git
2. Откройте проект в Android Studio.
3. Синхронизируйте Gradle (`Sync Now`).
4. Запустите на эмуляторе или реальном устройстве.
